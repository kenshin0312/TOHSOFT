Hiểu nhanh

10vị trí quảng cáo đang chạy (+2 khai báo nhưng chưa gắn vào màn nào)
105mã màn hình con để tắt riêng từng màn (72 banner bottom, 23 native tạo QR, 8 native empty, 2 inter scan result)
0 lầnkhởi động lại app. Rule áp dụng ngay khi đổi
  • Mỗi vị trí có một mã dạng <loại>_<vị trí>_genN, ví dụ interstitial_show_scan_result_gen1.
  • Mặc định tất cả ON. Chỉ vị trí nào khớp một rule tắt mới bị OFF.
  • Quảng cáo chỉ hiện khi cả hai điều kiện đúng: cờ cũ enable_* trên Firebase đang bật, và không bị ads_disable_rules_v1 tắt. Rule mới chỉ dùng để tắt, không bật lại được vị trí mà cờ cũ đang tắt.
  • JSON sai cú pháp hoặc sai kiểu dữ liệu ⇒ app giữ nguyên rule hợp lệ gần nhất (Last Known Good), không tự bật lại quảng cáo.
  • Gõ sai mã vị trí / màn / format ⇒ JSON vẫn hợp lệ, phần đúng vẫn áp dụng, phần sai bị bỏ qua và có cảnh báo. Ngoại lệ: mã màn của small_banner_bottom_gen1 và native_create_qr_gen1 không bị cảnh báo khi gõ sai (xem dòng dưới).
  • Mã màn của banner dưới và native tạo QR lấy theo tên màn (getScreenName()) đang hiển thị, ví dụ small_banner_bottom_gen1:History, native_create_qr_gen1:CreateUrl. Với banner dưới, mọi màn nhập nội dung tạo QR gộp chung mã createQr, mọi màn kết quả scan gộp chung mã ScanResult. Mã phân biệt hoa thường, nên copy từ Danh sách vị trí.

Thứ tự ưu tiên lý do tắt

Khi một vị trí khớp nhiều rule, dialog kết quả chỉ hiện lý do đứng trước:

Cách đổi cấu hình

Cách 1: màn Testing trong app (QA dùng cách này)

  1. Cài bản Tester hoặc TesterGDPR (com.tohsoft.qrcodetesting). Bản Product không có màn Testing.
  2. Vào Settings → Testing → mục Ads Disable Rules (ads_disable_rules_v1).
  3. Chọn một trong:
    • Nhập JSON...: dán JSON từ mục JSON mẫu.
    • Một preset có sẵn: danh sách đã sinh sẵn mọi format, mọi vị trí, mọi màn con của native empty và inter scan result, một số màn tiêu biểu của banner dưới (createQr, ScanResult, 5 tab chính, Card/URL Scanner) và native tạo QR (CreateUrl, CreateWifi, CreateText, CreateMyCard), cùng các case JSON lỗi. Màn khác thì dùng Nhập JSON... với JSON copy từ Danh sách vị trí. Preset theo build tự lấy đúng versionCode của bản đang cài.
    • Xóa override (dùng Firebase): bỏ JSON tự nhập, quay lại giá trị trên Firebase.
  4. App áp dụng ngay và hiện dialog Kết quả áp dụng: nguồn (Override / Firebase), JSON đang đọc, cảnh báo, danh sách vị trí OFF kèm lý do, danh sách màn con OFF kèm lý do.
  5. Bấm back để về màn chính (app mở lại MainActivity), rồi đi tới màn cần kiểm tra.

Override thắng Firebase. Khi đã nhập JSON ở màn Testing, mọi thay đổi trên Firebase Console bị bỏ qua. Muốn test luồng Firebase thì phải chọn Xóa override trước.

Cách 2: Firebase Remote Config (dev / PM thao tác)

  • Sửa parameter ads_disable_rules_v1 trên Firebase Console rồi Publish.
  • App đang mở nhận config qua Real-time Remote Config và áp dụng ngay, không cần mở lại app. Nếu máy offline, config mới áp dụng ở lần app fetch thành công tiếp theo.
  • Giá trị mặc định trong app là chuỗi rỗng ⇒ không tắt gì.

Xem log: lọc Logcat theo AdRemoteControl. Mỗi vị trí bị tắt có dòng OFF <mã>, reason = <lý do>; JSON lỗi có dòng không hợp lệ, dùng Last Known Good; mã gõ sai có dòng Placement lạ / Format lạ / Key lạ.

Điều kiện trước: các cờ cũ trên Firebase phải đang bật cho vị trí cần test (xem cột “Cờ cũ phải bật” ở Danh sách vị trí). Nếu cờ cũ tắt thì vị trí đó vốn đã OFF, không kiểm tra được rule mới. JSON mẫu

Bấm Copy rồi dán vào Settings → Testing → Ads Disable Rules → Nhập JSON....

Mẫu 1 – Mặc định, không tắt gì

Tương đương để rỗng trên Firebase.

{
  "disable_all": false,
  "disabled_builds": [],
  "disabled_formats": [],
  "disabled_placements": []
}

Mẫu 2 – Tắt banner dưới màn chính

Banner cuối màn chính biến mất, các vị trí khác giữ nguyên.

{
  "disabled_placements": ["small_banner_bottom_gen1"]
}

Mẫu 3 – Tắt mọi quảng cáo toàn màn hình

Tắt interstitial, inter-open, app-open. Chỉ còn banner và native.

{
  "disabled_formats": ["interstitial", "inter_open", "app_open"]
}

Mẫu 4 – Tắt toàn bộ quảng cáo

Một cờ tắt tất cả vị trí.

{
  "disable_all": true
}

Mẫu 5 – Tắt theo build

198 là versionCode bản Tester 1.62. Thay bằng versionCode bản đang cài; đổi sang số khác thì quảng cáo hiện lại.

{
  "disabled_builds": [198]
}

Mẫu 6 – Tắt riêng từng màn

Native empty chỉ tắt ở History; interstitial chỉ tắt ở Convert result của Image to Text; banner dưới chỉ tắt ở các màn nhập nội dung tạo QR; native tạo QR chỉ tắt ở màn tạo QR URL.

{
  "disabled_placements": [
    "native_empty_screen_gen1:history",
    "interstitial_show_scan_result_gen1:img2text_convert_result",
    "small_banner_bottom_gen1:createQr",
    "native_create_qr_gen1:CreateUrl"
  ]
}

Mẫu 7 – Ưu tiên lý do

Format native và màn con cùng khớp. Lý do hiển thị phải là FORMAT.

{
  "disabled_formats": ["native"],
  "disabled_placements": ["native_empty_screen_gen1:history"]
}

Mẫu 8 – Mã gõ sai

Cố ý gõ sai để kiểm tra cảnh báo. Chỉ app_open bị tắt.

{
  "disabled_formats": ["app_open", "rewarded"],
  "disabled_placements": [
    "result_interstitial_gen1",
    "native_empty_screen_gen1:histroy"
  ],
  "foo": 1
}

Mẫu 9 – JSON lỗi

disable_all là string thay vì boolean ⇒ JSON không hợp lệ, app giữ rule cũ.

{
  "disable_all": "true"
}

Danh sách vị trí (119)

Gõ tên màn hình hoặc mã vào ô tìm kiếm để tra nhanh. Tick các vị trí muốn TẮT: JSON bên dưới tự cập nhật, bấm Copy JSON rồi dán vào Settings → Testing → Ads Disable Rules → Nhập JSON... hoặc gửi dev dán lên Firebase.

Mã màn của banner dưới = tên màn (getScreenName()) đang hiển thị trên cùng: màn mở chồng nếu có, không thì tab đang chọn. Hai nhóm được gộp một mã: mọi màn nhập nội dung tạo QR dùng createQr, mọi màn kết quả scan dùng ScanResult. Mã phân biệt hoa thường. Native tạo QR cũng lấy mã theo tên màn tạo QR (native_create_qr_gen1:CreateUrl…), không gộp. Mã màn bất kỳ của small_banner_bottom_gen1 và native_create_qr_gen1 đều không bị cảnh báo Placement lạ, nên gõ sai sẽ không có cảnh báo, hãy copy từ bảng.

Không có vị trí nào khớp từ khoá.

JSON từ các vị trí đã tick 0

{
  "disabled_placements": []
}

Mặc định = không tick gì (app mặc định bật mọi vị trí). Mã phải gõ đúng cả hậu tố _genN: app so khớp chính xác, small_banner_bottom (thiếu _gen1) sẽ bị bỏ qua và báo Placement lạ. Muốn tắt theo loại hoặc toàn bộ thì dùng disabled_formats / disable_all ở JSON mẫu.

Báo lỗi

Một bug report cần có:

  • Mã vị trí (hoặc mã màn con) và tên màn hình đang kiểm tra.
  • JSON đã dùng, và nguồn: Override ở màn Testing hay Firebase.
  • Ảnh chụp dialog Kết quả áp dụng (có lý do OFF và cảnh báo).
  • Ảnh / video màn hình, trạng thái mạng (wifi, 4G, offline).
  • versionName / versionCode bản đang cài và flavor (Tester / TesterGDPR).
  • Nếu có: đoạn Logcat lọc theo AdRemoteControl.
